# Contributing to @iberi22/swal-local

Thank you for your interest in contributing!

## Workflow

1. **Fork and Clone:** Fork the repository and clone it to your local machine.
2. **Branching:** Create a new branch for your feature or bugfix (e.g., `feat/add-new-capability` or `fix/tts-bug`).
3. **Run Tests:** Ensure all tests pass before submitting your pull request. Run `npm run test` locally.
4. **Commits:** We follow Conventional Commits format (e.g., `feat: ...`, `fix: ...`, `chore: ...`).
5. **Pull Request:** Open a pull request against the `master` branch. Ensure the CI pipeline passes.
