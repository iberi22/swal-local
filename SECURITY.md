# Security Policy

## Supported Versions

The following versions of the project are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| master  | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories by clicking "Report a vulnerability" on this repository.

**Do not open public issues or pull requests for security reports, and do not mention or speculate about any specific vulnerability in public discussions.**

## Response Targets and Disclosure

- **Acknowledgment:** We aim to acknowledge vulnerability reports within 5 business days.
- **Status Update:** A status update will be provided within 14 days of the initial report.
- **Coordinated Disclosure:** We follow coordinated disclosure practices to ensure vulnerabilities are fixed before being made public.
- **Bug Bounty:** Currently, there is no bug bounty program for this project.
